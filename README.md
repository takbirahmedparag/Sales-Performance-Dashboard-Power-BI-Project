# Sales-Performance-Dashboard-Power-BI-Project
This is my first Power BI dashboard where I analyzed sales performance by country, category, and time. I cleaned data in Power Query, built relationships, and created measures like sales, cost, profit, and orders to generate clear business insights.

## Project Objective
The main goal of this project is to analyze overall sales performance and understand business insights like sales trends, cost, profit, and target comparison.

## Key Insights & Analysis
In this dashboard, I have created:
•	Total Sales and Total Cost by Country
•	Total Sales by Month (Trend Analysis)
•	Target vs Total Sales Comparison
•	Total Sales by Country (Map View)
•	Total Sales by Category
•	Total Sales by Year

## Features
•	Interactive Slicers (Country & Category)
•	KPI Cards (Total Sales, Profit, Order Count, Average Order Value)
•	Clean and simple dashboard design

## Story & What I Solved
This is my first dashboard project, and the journey was not easy. I faced many real problems and learned by solving them step by step.
At the beginning, I was confused about measure vs calculated column and didn’t understand where to use each. Then I learned how measures work dynamically and columns are used for grouping.
I struggled while creating Total Sales, Total Cost, Profit, Order Count, and Average Order Value. I also learned how to use RELATED function to connect tables and calculate correct values.
Another challenge was data modeling. I created relationships between multiple tables and understood how a proper model helps in analysis.
I also faced issues with date data, then I learned how to extract month and year for trend analysis.
The hardest part was visual design. Choosing colors, fonts, and layout took a lot of time, but I improved step by step and made the dashboard clean and readable

## Process
1.	Loaded dataset and transformed data using Power Query
2.	Imported cleaned data into Power BI
3.	Created relationships between tables (Data Modeling)
4.	Built DAX measures (Sales, Cost, Profit, Orders, Average)
5.	Designed dashboard step by step with proper charts
